Core capabilities

Everything required for an AI backend.

The V1 API is organized into independent modules covering authentication, AI providers, conversations, search, subscriptions and administration.

🔐

Authentication

Registration, login, JWT access tokens, refresh tokens, logout, password hashing and email verification.

👤

User Management

User profiles, password management, account status and role-based access control.

🤖

AI Providers

Manage OpenAI, Anthropic and Google AI providers with model management and encrypted API credentials.

💬

AI Chat

Send prompts to different AI providers, receive responses and maintain conversation history.

⚡

Subscriptions

Free and premium plans with usage limits, plan upgrades, downgrades and monthly request tracking.

🔎

AI Search

Search integration with search history, recent searches, suggestions and caching.

🛡️

Administration

Dashboard data, users, subscriptions, providers, usage statistics, request logs and system health.

📊

Request Logging

Track API requests, response status, response time and request metadata for administration and debugging.

📚

Swagger Documentation

Interactive OpenAPI documentation for exploring endpoints, authentication, request bodies and responses.

Architecture

Modular by design.

EchoGPT follows a modular NestJS architecture. Each major business capability is isolated into its own module, making the backend easier to maintain, test and extend.

├── chat/

├── search/

├── admin/

├── prisma/

Security

Built with security in mind.

JWT Authentication

Access tokens and refresh tokens are used to secure authenticated API resources.

Password Hashing

User passwords are securely hashed instead of being stored as plain text.

Encrypted Provider Keys

AI provider API credentials are encrypted before being stored in the database.

Role-Based Access

Administrative endpoints are protected using role-based authorization.

Quick start

Run EchoGPT locally.

Install dependencies, configure your environment variables and start the development server.

Terminal 
git clone  https://github.com/Eshrak20/EchoGPT_Nest.js_Postgres.git

cd EchoGPT_Nest.js_Postgres

bun install

bunx prisma migrate dev

bun run start:dev
